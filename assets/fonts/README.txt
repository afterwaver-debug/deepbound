DEEPBOUND FONT
==============

Recommended font: Pixel Operator
Expected filename:
    PixelOperator.ttf

Place PixelOperator.ttf in this folder. DEEPBOUND will automatically use it
for the menus and HUD text.

Pixel Operator is by Jayvee Enaguas (HarvettFox96). The author's font listing
states that the font is licensed under CC0.
Source: https://www.dafont.com/pixel-operator.font

Fallback order:
1. PixelOperator.ttf
2. font.ttf (if present)
3. Pygame's default font
